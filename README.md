# Hello World

A minimal Next.js App Router application, created with `create-next-app`, TypeScript, ESLint, and npm.

## Run locally

```sh
npm ci
npm run dev
```

Open http://localhost:3000. Edit `app/page.tsx` to change the greeting.

## Check and build

```sh
npm run lint
npm run build
npm start
```

## IntelliJ IDEA

Open this repository folder in IntelliJ IDEA. To clone it on another machine, choose **Get from Version Control** and enter:

```text
https://github.com/WinnieChen01/week1-hello-world.git
```

## Deploy with Vercel

1. Push the `main` branch to GitHub.
2. In https://vercel.com/new, import `WinnieChen01/week1-hello-world`.
3. Select the Next.js framework preset and keep the repository root as the root directory.
4. Click **Deploy**. No environment variables are needed.

Once connected, pushes to `main` trigger production deployments.
